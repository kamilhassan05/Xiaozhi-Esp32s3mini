How to Flash

  • 1
    Install USB Drivers Most systems detect ESP32-S3 automatically. If not, install the CP210x driver or CH340 driver.
  • 2
    Enter Bootloader Mode Hold the BOOT button, press RESET once, then release BOOT. The board is now in flash mode.
  • 3
    Connect via USB Plug your ESP32-S3 into your computer using a data-capable USB cable (not a charge-only cable).
  • 4
    Click "Flash Firmware" Select the correct COM port in the browser dialog, then click Install. Wait for the process to complete (about 30–90 seconds).
  • 5
    Press Reset After flashing completes, press the RESET button on your board. Xiaozhi AI Assistant will boot up.
⚠️
Before you flash Flashing will erase existing firmware on the device. Make sure you are using a data USB cable, not a charge-only cable. If the port does not appear in the browser dialog, try a different cable or USB port.

Troubleshooting

  • No serial port appears in browser dialog Use a data USB cable. Try a different port. Install the correct USB driver (CP210x or CH340). On Windows, check Device Manager.
  • Failed to download manifest Verify manifest.json is in the repo root. Check GitHub Pages is enabled. Open the manifest URL directly in browser to confirm it loads.
  • Flashing fails or times out Hold BOOT, press RESET, release BOOT to enter bootloader mode manually, then retry.
  • GitHub Pages 404 on firmware files Confirm all .bin files are inside the firmware/ folder in your repo. Paths in manifest.json must match exactly (case-sensitive).
  • Page loads but button does nothing You are not using a supported browser. Switch to Chrome or Edge on a desktop computer.
  • Garbled audio / distorted sound after flash Make sure the MAX98357A speaker amplifier is powered from 5V, not 3.3V. 3.3V will cause audio distortion.
  • How to verify BIN files are accessible Open https://your-username.github.io/your-repo/firmware/bootloader.bin in your browser. If it downloads, the path is correct.
  • How to clear browser cache Press Ctrl+Shift+R (Windows/Linux) or Cmd+Shift+R (Mac) for a hard reload. Or clear cache from browser settings.
