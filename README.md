# Xiaozhi-Esp32s3mini
Xiaozhi AI Assistant is a compact AI desktop companion powered by the ESP32-S3 Super Mini Zero (4MB Flash, 2MB PSRAM). It features a 1.3" OLED with animated eyes, INMP441 mic, MAX98357A amplifier, speaker, 4 buttons, and a relay. Say "Hi Esp" or "Alexa" to chat, ask questions, and control devices. Dark Mode supported.
